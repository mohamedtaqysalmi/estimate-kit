# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use the
["Report a vulnerability"](https://github.com/mohamedtaqysalmi/estimate-kit/security/advisories/new)
form on the Security tab of this repository. It creates a private report that only the maintainer can see.

This project is maintained by one person, so a reply can take a few days.

## Supported versions

The project is at an early stage (0.0.x). Only the latest commit on `main` receives fixes.
